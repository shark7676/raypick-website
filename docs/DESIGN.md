# Raypick 홈페이지 리뉴얼 설계 (2026-10-08 확정)

## 1. 무엇을, 왜
- raypick.co.kr 회사 홈페이지를 디자인부터 전면 새로 만든다.
- **목적: 회사 신뢰도.** 제휴사·투자자·스토어 심사·정부지원사업 담당자가 "실제로 앱을 출시하는 회사"라고 느끼게 한다.
- 메시지는 하나: **앱을 만드는 회사.** (유튜브·미디어 소개는 뺀다)

## 3. 페이지 구성
**메인 한 페이지 (위 → 아래)**
1. **첫 화면 (시안 A · RAY):** 3D 로고 R(남색 금속) + 빛나는 유리 삼각형, 뒤에서 퍼지는 빛줄기. 제목 "일상을 비추는 앱을 만듭니다."
2. **앱 궤도 (시안 B · ORBIT):** 스크롤하면 로고가 가운데로 오고, 앱 5개가 3D 아이콘이 되어 궤도로 나온다. 끌어서 돌릴 수 있다. "하나의 스튜디오, 계속 늘어나는 세계." (앱이 계속 늘어나므로 숫자를 넣지 않음, 2026-10-10)
3. **새벽빛 → 출시 앱 3개 (시안 C · STUDIO):** 아래에서 파란 새벽빛이 차오르며 화면이 밝아진다. 3D 휴대폰(고정)에 앱별 실제 화면이 돌아가고, 왼쪽 글이 앱마다 넘어간다.
4. **출시 예정 2개:** PARRYTHM, 하루요 카드.
5. **회사 소개:** 확인된 사실만.
6. **문의:** `admin@raypick.co.kr` 메일 버튼 (양식 없음).
7. **바닥글:** 주식회사 레이픽 · 대표 신상권 · 사업자등록번호 781-86-04185 · 경상남도 창원시 진해구 연구단지1길 16, 207-2호.

**앱별 소개 페이지 `/apps/[slug]` (5개):** 큰 3D 휴대폰, 스크린샷, 설명, 스토어 버튼, 공식 사이트 링크.

옛 주소 `/about`, `/services`, `/contact`는 메인의 해당 위치로 넘겨준다(redirect).

## 4. 디자인 기준
- 색: 배경 #03050b(어두움) / #eef2f8(밝음), 남색 #132140, 파랑 #3a7cf0, 하늘 #8cc6ff.
- 글꼴: 본문·제목 Pretendard, 영문 포인트 Michroma (로고 글자와 비슷한 넓은 글꼴).
- 로고: `public/brand/` (로고.png를 SVG로 다시 그림, 원본 일치율 97.7%).
- 언어: 한국어 + 영어 전환.

## 5. 기술
- Next.js 16 (App Router) 그대로. 3D는 **three.js 0.186**을 직접 사용 (React용 3D 부품은 쓰지 않음 = 부품 최소화).
- 3D 화면은 2개만: ① 첫 화면+궤도(한 장면, 스크롤로 연출) ② 앱 소개 휴대폰.
- 화면 밖에 있을 때는 3D를 멈춘다. 휴대폰에서는 화질·입자 수를 낮춘다.
- 3D를 못 켜는 기기 / "움직임 줄이기" 설정: 그림으로 대체하고 내용은 전부 보이게.

## 6. 성공 기준
1. 휴대폰에서도 첫 화면이 3초 안에 보인다.
2. 앱 5개 정보·스토어 링크가 모두 정확하다 (링크 접속 확인).
3. 한국어 ↔ 영어 전환이 된다.
4. PC·휴대폰 어디서도 화면이 깨지지 않는다 (가로 넘침 없음).
5. 3D가 안 되는 환경에서도 내용이 전부 보인다.

## 7. 가정
- 방문자 정보를 모으지 않는다 (양식·추적 도구 없음).
- 배포는 지금 Vercel 프로젝트(`raypick`) + raypick.co.kr 그대로. **main에 올리면 바로 실제 사이트가 바뀌므로, 올리기 전 반드시 대표 확인.**
- 하루요 앱 아이콘이 아직 없어 임시 파스텔 아이콘을 쓴다 (진짜 아이콘이 나오면 교체).
